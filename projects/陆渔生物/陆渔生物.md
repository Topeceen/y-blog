## 项目介绍

- 基于室内水产养殖开发的数据管理系统，管理养殖数据，养殖人员信息，养殖人员任务等模块，同时链接小程序，方便养殖人员使用。

## 项目团队

- 1 产品、2 前端、两后端

## 项目技术栈

- 技术栈介绍：
- 开发工具 :Visual Studio Code
- 编程语言 :TypeScript 4.x + JavaScript
- 构建工具 :Vite 3.x
- 前端框架 :react 18.3.1
- 路由工具 :react Router 9.x
- 状态管理 :Redux 9.x
- UI 框架 :Semi design
- 可视化 :Echart 5.x
- 工具库 :"@reduxjs/toolkit + dayjs + countup.js 等等
- CSS 预编译 :Sass / Less
- HTTP 工具 : Axios
- Git Hook 工具 :husky
- 代码规范 :EditorConfig + Prettier + ESLint
- 提交规范 :Commitizen + Commitlint
- 自动部署 :Centos + Jenkins + Nginx
